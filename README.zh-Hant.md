# Luma 🌅
> 旅行攝影師的光線助手

---

## 專案簡介

Luma 是一個面向旅行攝影師的光線助手應用，幫助使用者在旅途中找到最佳拍攝時間與光線條件。

目標使用者是在旅途中帶著相機、想抓好光但不想做太多研究的攝影愛好者。

---

## 核心功能

### 1. 即時光線助手
- 自動取得使用者當前時間與位置
- 顯示當前光線階段（藍調 / 黃金時段 / 正午 / 日落）
- 告知使用者現在該怎麼拍，以及下一個好時段

### 2. 行程規劃
- 輸入地點與日期範圍
- 分析每日光線與天氣狀況
- 標出最佳拍攝日與時間區間

---

## 使用者設定

所有設定儲存在 `localStorage`，無需帳號。

---

## 本地開發

需求：
- .NET 9 SDK
- VS Code

啟動專案：
```powershell
git clone https://github.com/miemie123wang/Luma.git
cd Luma/Luma
dotnet run
```

在瀏覽器開啟 `dotnet run` 顯示的位址（例如 `http://localhost:5284`）。
